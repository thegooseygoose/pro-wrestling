# Pro Wrestling — Black Box Series

A fan remake of NES *Pro Wrestling* (1986), played in the browser.

**Play it:** https://thegooseygoose.github.io/pro-wrestling/

## Controls

| Keyboard | Pad | |
|---|---|---|
| Arrows | D-pad | Move (double-tap left/right to run) |
| Z | X | Punch |
| X | A | Kick |
| Enter | Start | Start / pause |

Exhibition, Tournament and CAW modes, 8 wrestlers with their own entrances and signature moves, the steel chair, top-rope moves, Irish whips, and the move list (in the main menu) shows how to do everything.
