ENTRANCE MUSIC
Easiest: put your songs in the "custom music" folder next to Pro Wrestling.exe (dist\custom music\).
They are picked up every time the game starts - no rebuild needed. Name each file after the wrestler:
  star.mp3       STAR MAN
  amazon.mp3     THE AMAZON
  todd.mp3       TODD QUALITY      (heavy.mp3 also works)
  lokombo.mp3    LOKOMBO
  scotty.mp3     SCOTTY MAC
  nick.mp3       NICK PRICE
  adonis.mp3     AIR ADONIS
  machete.mp3    MACHETE BROWN
  shawn.mp3      SHAWN MURPHY
  bronson.mp3    MATT BRONSON
  cremator.mp3   CREMATOR VON SLASHER
(Full names like "Matt Bronson.mp3" work too. mp3, ogg, wav or m4a.)
A wrestler with no file keeps his built-in chiptune theme.

Files dropped in THIS folder (as entrance_<name>.mp3) also work, but need the exe rebuilt.
